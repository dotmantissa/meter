# Meter architecture

The browser reads a bill locally with PDF.js, hashes its original bytes, and lets its owner check the extracted quantities. Only a fixed schema of quantities, dates and public tariff identifiers reaches the API. There is no upload endpoint or field for a name, address, account number or raw bill text.

Privy verifies email access. The server derives a separate managed signing account for each user from a stable server secret. The same seed must be configured on both hosts. Sponsorship atomically reserves a shared daily allowance and a per user grant in one PostgreSQL function before broadcasting. Unknown broadcast outcomes remain reserved for reconciliation.

Neon stores indexes and job state. An audit has its own original receipt lifecycle. Each subsequent operation has a separate UUID, receipt, target contract addresses, lease and status. Atomic reservations and a unique active operation index prevent overlapping actions. Only that operation's successful finalized receipt completes it. A failed auxiliary action never changes the original verdict status. Cancellation checks the actual escrow even if the audit status is unavailable.

Reports periodically read the latest finalized contract state after the original transaction is finalized. The cache records its last successful synchronization and failures. Revision comparisons prevent older reads overwriting newer snapshots. Address comparisons also discard delayed responses from superseded contracts. Public pages keep polling after finalization. The index cannot establish a verdict by itself.

The registry preserves all three complete public PDFs and their SHA256 hashes under strict equivalence. A new audit independently fetches and verifies the currently published bytes. An appeal or monthly confirmation uses the identical committed archive, verifying its hashes again. A changed live source blocks new adjudication but does not erase historical evidence. Both paths enforce the original period and effective dates. The archive endpoint serves only registry evidence and verifies its hash before returning a PDF.

Every page is extracted. The contract rejects documents above 8 MB or 700 pages, individual text above 500,000 characters, and combined evidence above 500,000 characters. It never silently samples pages. Each validator independently establishes applicability, dates and rates. Extracted parameters and classifications must match exactly. Arithmetic uses integer micro dollars and Wh inside a sandbox and rounds each billed component half up to cents. Totals must agree within 0.5 percent. The deterministic caller recomputes persisted amounts after consensus. Unsupported evidence produces an inconclusive result.

Every revision has an immutable snapshot, reason, actor and timestamp. A sticky correction marker survives subsequent confirmations. A material hash covers classification, charges and extracted parameters while excluding revision metadata. This distinguishes repeated confirmation from a correction and governs settlement. History is public and paginated.

Owners receive one unbonded scheduled confirmation every 30 days. Earlier reconsideration requires the same bond as a public challenge. Bonded challenges are repeatable with a separate one hour cooldown for each caller and audit; no stranger can consume another person's appeal slot. A material correction queues return of the bond. GenLayer selects validators, so disjoint panel identities are not guaranteed.

An eligible owner may deposit an actual Studio success fee. The operator attests the utility credit, an explicit external trust boundary. The fee equals deposit times recovered amount divided by original disputed amount, rounded down. The remainder is refunded. An unchanged confirmation retains eligibility. A changed material hash invalidates the entire fee. The audit queues permissionless escrow synchronization after finalization, which queues a native refund. Anyone may safely retry synchronization; a depositor may cancel while the claim is open. Payouts finalize separately from the verdict. No contract issues dollars or a utility credit.

Recurring checks require consent and reuse existing anonymous facts. New bills require a new local extraction. Shared source jobs include the registry address. Confirmed execution failures, cancellation and undetermined outcomes enter bounded retry backoff. Unknown broadcasts remain distinct. Operation receipt reconciliation continues independently of scheduling.

The migration preserves legacy contract addresses and the latest legacy snapshot. Owners must cancel legacy deposits before moving a review. Import requires all three old evidence hashes to match the archived documents and performs fresh consensus. Complete future history starts on the replacement contract; unavailable past revisions are explicitly disclosed.
